# Codex Start Checklist

Before implementation, Codex should answer:

1. Which files did you read?
2. What is the current project structure?
3. Is the Tailwind/PostCSS setup correct?
4. What phases will you implement?
5. Which assets need GPT Image 2 generation?
6. Which commands will you run for verification?
7. What approvals do you need from the human operator?

Do not modify code until the plan is approved.
